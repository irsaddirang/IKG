# Render verification — manroland R700 IEC wiring diagrams

Generated by `pipeline/render.py`; verified independently by reading every PNG
header, decoding a random sample with Pillow, and inspecting three sheets visually.

**Configuration:** 1-bit bilevel PNG, **300 DPI**, threshold 160, no dithering.
**Run:** 1351 pages, 6 worker processes, 66.8 s wall clock, **0 failures**.

## 1. Corpus integrity

Every expected file exists, is a structurally valid PNG, has the exact pixel
geometry implied by its page, and is 1-bit greyscale.

| Document | Expected sheets | Files found | Missing | Bad | Size |
|---|---:|---:|---:|---:|---:|
| `+FB` | 22 | **22** | 0 | 0 | 1.34 MB |
| `+Ax` | 403 | **403** | 0 | 0 | 26.82 MB |
| `+BA_Cx_DA` | 247 | **247** | 0 | 0 | 15.87 MB |
| `+EA` | 407 | **407** | 0 | 0 | 27.10 MB |
| `+FA` | 58 | **58** | 0 | 0 | 3.77 MB |
| `+Jx` | 214 | **214** | 0 | 0 | 14.33 MB |
| **TOTAL** | **1351** | **1351** | **0** | **0** | **93.55 MB** (89.22 MiB) |

Checks applied per file:

* **Filename convention** — every file matches `<DOCKEY-without-plus>_<SHEET:04d>.png`
  inside `images/<DOCKEY>/`; zero stray or misnamed files.
* **Completeness** — every sheet number `1..len(pdf)` is present exactly once, per document.
* **Pixel geometry** — IHDR width/height compared against `page.rect` × 300/72.
  All 1351 are **4961 × 3508 px** (1190.55 × 841.89 pt × 4.16667 px/pt), the
  largest legal A3 raster at this DPI.
* **Format** — IHDR confirms bit depth **1**, colour type **0** (greyscale) on every file,
  i.e. the 2-level encoding was actually used, not merely a small 8-bit image.
* **Non-empty** — smallest file is 33.2 KB; a failed/truncated write would be far smaller.
* **Decode** — 40 randomly chosen PNGs were fully decoded with Pillow (`im.load()`),
  all succeeded and all reported mode `1`. No CRC or truncation errors.
* **No debris** — zero `.tmp` files left behind (writes are atomic via `os.replace`).

Size range 33.2 KB – 138.2 KB per page (mean 67.6 KB). The 2.3× spread is expected:
sparse cover/index sheets versus the 1,900-path circuit sheets.

## 3. Visual spot-checks

Crops were taken **from the delivered 300 DPI PNGs** at native resolution
(no re-render, no upscaling) so what was inspected is exactly what a consumer
of `images/` will see.

### `+Ax` sheet 21 — STRÖMLAUFPLAN / CIRCUIT DIAGRAM → **PASS**

Region: x 150–430 pt (xrefs), x 665–1140 pt (title block).

* Title block fully legible: `Masch.-Type: R700`, `Serie: 7758-`, `IEC (N) 1`,
  `UL (M) 0`, `8039G38I902`, `Blatt: 21 - 403`, `DIN A3`, zone letters `E F G H`.
* Cross-references **`/17.B`, `/17.D`, `/17.C`, `/154.D`, `/48.A`** all crisp — the
  slash, the dot and the trailing capital are individually distinct.
* Rotated 90° annotation ladder (`-24V.X1.A566:4`, `-24V.X13.A343:1`,
  `-24V.K048:A2`) reads correctly even though the glyphs are only ~10 px wide.
* 0.85 pt dropper wires are continuous single-weight lines; the vertical bus at
  left runs unbroken across the whole crop; junction dot is a solid disc.

### `+EA` sheet 200 — REFERENZMODUL / REFERENCE MODULE → **PASS**

Region: x 300–520 pt (pin tables), x 665–1140 pt (title block).

* Two full pin tables legible: headers `PIN`, `BYTE.BIT`, `STROMPFAD`, and every
  row of the `3A/3B/3C` → `26A/26B/26C` ladder.
* Dense `.l` cross-references **`/328.B`, `/175.D`, `/175.E`, `/331.A`, `/336.A`,
  `/330.H`, `/334.B`, `/334.C`, `/336.E`** all readable at native size.
* Table rules (many short 0.85 pt horizontals in a tight grid) are unbroken — no
  dotted or vanished row separators, which is the failure mode that would have
  disqualified 1-bit output.
* Title block: `8039G38E915`, `Blatt: 200 - 407`, unit-specific `ULL (M) 1`
  (differs from +Ax's `0`, confirming per-file content is being captured).

### `+FB` sheet 9 — `#67` annotation cluster → **PASS**

Region: x 700–900 pt around the four `#67` tags.

* **`#67` renders as a clean glyph** — the `#` crossbars and the `6`/`7` are
  separable at 300 DPI, which was the tightest asked-for check.
* All four reference strings legible with their pagination: `+A497/2-X1.A463:1`,
  `+A497/2-X4.A463/1:4`, `-X1.A368:2`, `-A244:bn`, each paired with a signal-arrow
  symbol and targets `/17.D`, `/17.E`, `/12.C`, `/13.G`.
* Smallest text present — the `:1` / `:4` suffixes and the `:` inside `-A244:bn` —
  survives as distinct pixels.
* Wires: long horizontals are continuous and uniform; the right-angle corner in
  the top entry and the arrow outlines show intact vertices, no gaps at joins.
* Title block: `=R700`, `7759`, `Norm/Frequenz: B2_10: IEC / 50Hz`,
  `B2_15: IEC / 60Hz`, `B2_20: UL/cUL/60Hz`, `8039G38K159`, `Blatt: 9 - 22`,
  `ansstatt: 8039G38I415` — all crisp.

### Verdict

Text remains **fully legible in a native-resolution crop** on all three sheets,
including 7.4 pt body text, rotated annotations, and the `#` and `/NN.X` symbols.
Hairlines are **unbroken**. The hard requirement is met with no compromise.

## 5. Failures

**None.** `pages failed: 0`; `logs/render_failures.json` was not created because
there was nothing to record. The 8 pages reported as `skipped` are `+FB` sheets
1–8, which had already been rendered by the pre-run smoke test and were correctly
detected as valid and reused — legitimate resume behaviour, not a shortfall.
`--force` would have re-rendered them.

## 6. Throughput

1351 pages in 66.8 s with 6 workers ≈ **20.2 pages/s**. A single-worker run was
measured at ~0.28 s/page (~6 min total), so the parallel path is a ~5.5× speedup.
Resume, `--only`, `--pages`, `--force`, `--jobs`, `--dpi` and `--mode` were all
exercised during development.
