# D — Document map

What each of the six documents covers, how its sheets are organised, and how
the documents relate to the physical machine. Use this to decide **which
volume to open** before searching for a device or function.

## The press and its drawing sets

The manroland **R700** is a sheet-fed offset press. Paper runs
feeder → printing units → coating module → delivery. Each major module has its
own drawing set:

## Reading order recommended for a new question

1. **Start with `+Ax` if the question is about the control system / HMI /
   console**, because it holds the densest signal-level reference tables.
2. **Start with `+EA` or `+BA_Cx_DA` for anything about a printing unit.**
   `+EA` is the largest volume (407 sheets) and carries the printing-unit
   wiring; `+BA_Cx_DA` adds the main switch cabinet and other unit variants.
3. **`+Jx` covers the first printing module and the feed register** — the
   infeed side.
4. **`+FA` covers the delivery**, and `+FB` the coating module plus delivery
   options.
5. Cross-references **never leave a document**. If a wire seems to disappear,
   check that you are still inside the same document.

## How to tell which document a device belongs to

Devices are numbered per documentation set, and the same designator can exist
in more than one volume. Always resolve a tag **together with its document**:

- Use `03_INDEX/INDEX_DEVICES.md`, which lists every sheet each tag appears on
  (cross-document).
- Use `03_INDEX/INDEX_SECTIONS.md` to find the section that names the function
  you are chasing.
